# EmmyTech Facebook Page Widget

A lightweight WordPress plugin that allows administrators to display a Facebook Page on their WordPress website using a configurable Facebook Page URL.

## Overview

The plugin provides a simple way to embed a Facebook Page without requiring users to manually edit theme files.

It is designed with a straightforward WordPress administration interface and a lightweight implementation suitable for business and content-focused websites.

## Features

* Facebook Page URL configuration
* Simple WordPress admin interface
* Easy installation and configuration
* Responsive frontend display
* WordPress-native implementation
* Lightweight architecture
* No hard-coded Facebook Page URL
* Easy integration into WordPress websites

## Technology

* PHP
* WordPress
* HTML5
* CSS3
* JavaScript

## Installation

### Method 1 — WordPress Dashboard

1. Download the plugin.
2. Log in to WordPress.
3. Navigate to **Plugins → Add New → Upload Plugin**.
4. Upload the plugin ZIP file.
5. Install and activate the plugin.
6. Open the plugin settings.
7. Enter the Facebook Page URL.
8. Save the configuration.

### Method 2 — Manual Installation

1. Download or clone this repository.
2. Copy the plugin directory into:

```text
/wp-content/plugins/
```

3. Activate the plugin from the WordPress administration dashboard.
4. Configure the Facebook Page URL.

## Usage

After activation, configure the Facebook Page URL from the plugin settings.

The configured Facebook Page can then be displayed using the functionality provided by the plugin.
